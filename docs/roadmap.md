# Roadmap

## Phase 0 — Project Foundation (current)

- Runnable package and Windows setup instructions
- PySide6 shell with six placeholder pages
- Quality-tool configuration and smoke tests
- Architecture and decision records

## Later phases (gated)

Detailed planning for ingestion, normalized storage, deterministic replay, strategy APIs,
execution simulation, experiments, and analytics begins only after Phase 0 is accepted.
Options, Rust migrations, AI assistance, Monte Carlo, and optimization remain explicitly
out of scope until their prerequisites are correct and tested.
