# Exact version pins for the supported environment (Phase 1.8C, ADR-008).
#
# This is a pip *constraints* file, not a requirements file: it installs
# nothing by itself. It caps every package pip decides to install — direct or
# transitive — to one exact version, so two installs from the same commit
# resolve identically on Windows and Ubuntu. Packages that only appear on one
# platform (e.g. colorama, a Windows-only pytest dependency) are simply unused
# constraints elsewhere, which is why a single cross-platform file works where
# a frozen requirements list would not.
#
# Install:        python -m pip install -e ".[dev]" -c constraints.txt
# Regenerate:     python -m pip freeze --exclude-editable > constraints.txt
#                 (from an activated venv that was installed with the command
#                 above, after deliberately upgrading; restore this header,
#                 review the diff, and run the full test suite before
#                 committing)
#
# Scope, stated honestly: these are version pins, not hash pins. They make
# resolution deterministic; they do not authenticate artifacts or freeze the
# wheel per platform. Hash-level locking is recorded as future work in
# ADR-008. Runtime and dev dependencies are pinned together because the
# project currently ships one supported environment, in which the tests run.
#
# No secrets, no local paths, no editable references belong in this file.
